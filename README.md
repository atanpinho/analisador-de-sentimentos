# Analisador de Sentimentos Inteligente

Projeto universitário focado no desenvolvimento de um sistema capaz de analisar textos e classificar emoções automaticamente utilizando Python.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem Principal:** Python 3
* **Controle de Versão:** Git e GitHub
* **Ambiente de Trabalho:** Visual Studio Code

## 🚀 Status do Projeto: Fase 1 (Back-End) Concluída!

O motor principal do sistema foi totalmente desenvolvido e testado com sucesso.

### 🧠 O que foi implementado:
- **[x] Inteligência Artificial Nativa:** Integração com o modelo `pysentimiento/bertweet-pt-sentiment`, alcançando **98,92% de precisão** na análise de textos em Português do Brasil [21:19].
- **[x] Criação do Ambiente Virtual (venv):** Infraestrutura totalmente blindada e isolada utilizando a pasta `venv` [21:04].
- **[x] Laço Interativo Contínuo:** Implementação da estrutura `while True` e comando `input()`, permitindo que o usuário digite frases de forma perpétua sem fechar o programa [21:19].
- **[x] Encerramento Elegante:** Filtro de tomada de decisão com o comando `if` e interrupção por `break` para fechar o sistema de forma limpa ao digitar a palavra "sair" [21:19].
